**Order form**

- this is an order form using react

- **vercel Live link :** [(https://order-form-react.vercel.app/)] 
- various jsx is used to make form :
 
        - Text input -> name
  
        - Number input -> phone, age, quantity
  
        - Email-> Email
  
        - Radio button-> Gender
  
        - Select, options->payment method
  
        - Textarea-> Address, Comment
  
        - Checkbox-> agree section
  
        - Button-> submit button
